QUICKSTART

Create your first client

Connect your application to Luma with typed requests, secure credentials, and a small configuration file.

i

Before you begin Create a project and copy its public identifier from the dashboard.

Install the SDK

Add the package using the package manager already used by your application.

pnpm add @luma/sdk

Configure the client

The client infers response types from your schema and returns structured errors.

import { createClient } from "@luma/sdk";

export const luma = createClient({
  projectId: "project_orbit_42",
  region: "auto",
});
