QUICKSTART

Create your first client

Connect your application to Luma with a typed client, secure credentials, and one small configuration file.

Before you begin

Create a project in the dashboard and copy its public project ID. Your secret key stays server-side.

Install the SDK

The JavaScript SDK works in modern browsers, Node.js, and edge runtimes.

$ pnpm add @luma/sdk

Configure the client

Create one client for your application and pass the project ID from your environment.

import { createClient } from '@luma/sdk'

export const luma = createClient({
  projectId: 'project_orbit_42',
  region: 'auto',
})

Make a request

The client infers response types from your schema and returns structured errors.

GET/v1/projects/:projectIdCopy
