# Development explorations

Explorations are short-lived design checkpoints for work that changes public behavior. They record the question, evidence, proposed contract, TDD slices, and exit gate before implementation begins. Accepted durable decisions move into an ADR; implementation status remains in the PRD and root plans.

| Exploration | Status | Outcome |
| --- | --- | --- |
| [`content-actions/`](./content-actions/) | Proposed; approval pending | Exact content handoff, Markdown viewing, resource actions, and lifecycle hardening |

Explorations may be revised while proposed. They are not shipped API documentation.
